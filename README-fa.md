# زندگی‌یار — بسته انتشار بازطراحی‌شده

## فایل‌های اصلی
- `index.html` — برنامه و نشان تازه در رابط کاربری
- `icon.svg` — آیکون هماهنگ با هویت بصری
- `manifest.webmanifest` — تنظیمات نصب PWA
- `sw.js` — سرویس‌ورکر با کش نسخه‌بندی‌شده و اولویت دریافت نسخه جدید HTML

## انتشار در GitHub Pages
1. فایل ZIP را استخراج کنید.
2. در مخزن `alirezaradfar2000-a11y/zendegiyar`، گزینه **Add file → Upload files** را بزنید.
3. پنج فایل داخل پوشه را در ریشه مخزن بارگذاری کنید و اجازه دهید فایل‌های هم‌نام جایگزین شوند؛ خود مخزن را حذف نکنید.
4. Commit کنید و چند دقیقه برای انتشار GitHub Pages صبر کنید.
5. برنامه را با نشانی Pages باز کنید. اگر نسخه قدیمی هنوز نمایش داده شد، یک بار تب را کاملاً ببندید و دوباره باز کنید؛ سرویس‌ورکر جدید با نسخه کش `v3` جایگزین نسخه قبلی می‌شود.

**نکته مهم:** برای حفظ داده‌ها، فعلاً گزینه Clear storage / پاک‌کردن داده‌های سایت را نزنید. اطلاعات ابری Supabase با جایگزینی این فایل‌ها حذف نمی‌شود؛ بااین‌حال پیش از هر پاک‌سازی مرورگر، از داده‌های محلی احتمالی نسخه پشتیبان بگیرید.
