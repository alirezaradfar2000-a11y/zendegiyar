# زندگی‌یار — راهنمای انتشار نسخه ۰۹

## فایل‌ها
- `index.html`: برنامه
- `manifest.webmanifest`: مشخصات نصب PWA
- `sw.js`: ذخیره پوسته برای استفاده آفلاین
- `icon.svg`: آیکون

## انتشار رایگان با GitHub Pages
1. در GitHub یک مخزن جدید بسازید (ترجیحاً Private اگر می‌خواهید سورس را محدود نگه دارید؛ توجه کنید GitHub Pages برای مخازن خصوصی ممکن است به طرح پولی نیاز داشته باشد).
2. چهار فایل را در ریشه مخزن بارگذاری و Commit کنید.
3. از Settings → Pages، گزینه Deploy from a branch را انتخاب کنید؛ Branch را `main` و Folder را `/ (root)` بگذارید و Save کنید.
4. پس از آماده‌شدن انتشار، نشانی Pages را با Chrome باز کنید و از منوی مرورگر Install app یا Add to Home screen را بزنید.

## نکات
- PWA برای ثبت Service Worker باید از HTTPS یا localhost بارگذاری شود؛ بازکردن مستقیم فایل با `file://` نصب‌پذیر نیست.
- کش آفلاین پوسته برنامه را نگه می‌دارد. ورود، بازیابی داده‌های ابری و همگام‌سازی نیازمند اینترنت هستند.
- پیش از عمومی‌کردن مخزن، مطمئن شوید هیچ فایل حاوی رمز، کلید محرمانه یا اطلاعات شخصی در آن نیست. کلید Supabase داخل مرورگر از نوع publishable است و باید با RLS محافظت شود.
- تغییرات برنامه را با افزایش نام کش در `sw.js` منتشر کنید تا نسخه جدید جایگزین کش قبلی شود.
